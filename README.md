# Assignment 1 - JavaScript Calculator

A fully functional calculator built with HTML, CSS and vanilla JavaScript.

## Assignment Requirement

Create a calculator using JavaScript functions to perform:

- Addition
- Subtraction
- Multiplication
- Division

Use an if-else or switch statement.

## Implementation

The `performOperation()` JavaScript function uses a `switch` statement for the four arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear button
- Backspace button
- Keyboard support
- Division-by-zero handling
- Visible operator while entering calculations
- Chained calculations
- Responsive layout

## Example

85 + 15 = 100

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
