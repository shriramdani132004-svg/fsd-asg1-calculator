# Assignment 1 - JavaScript Calculator

A fully functional calculator created using HTML, CSS and Vanilla JavaScript.

## Assignment Requirement

Create a calculator using JavaScript functions to perform:

- Addition
- Subtraction
- Multiplication
- Division

Use an if-else or switch statement.

## Implementation

The `performOperation()` function uses a `switch` statement for all four arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear
- Backspace
- Keyboard support
- Division-by-zero handling
- Visible selected operator
- Chained calculations
