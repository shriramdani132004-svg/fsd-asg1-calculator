# Assignment 1 - JavaScript Calculator

A clean JavaScript calculator built using functions and a `switch` statement.

## Assignment Requirement

Create a calculator using JavaScript functions to perform:

- Addition
- Subtraction
- Multiplication
- Division

The arithmetic logic uses a `switch` statement.

## Features

- Four basic arithmetic operations
- Decimal numbers
- Clear button
- Backspace button
- Keyboard support
- Division-by-zero error handling
- Responsive layout

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Example

`85 + 15 = 100`
